### 3. Season Accuracy & Blog 자동 업데이트 통합

**문제**:
- `season_results.json` — 매일 수동 실행 필요, launchd는 Google Drive 접근 불가로 실패
- `blog/` 포스트 — 매일 수동 생성 필요
- `cmd_deploy_web()` — predictions.json만 push하고 season/blog 누락

**해결**:
`main.py`에 두 함수 추가, `cmd_predict_scorecard()` 자동 호출:
1. `cmd_update_season_results()` — `update_season_results.update()` 자동 호출
2. `cmd_generate_blog(game_date)` — 어제 블로그 포스트 자동 생성 (중복 방지)
3. `cmd_deploy_web()` — git add에 season_results.json + blog/ 추가

**실행 플로우 (이제 `python3 main.py` 한 번으로 완결)**:
```
과거 결과 업데이트 → 오늘 예측 → season_results 갱신 → 블로그 생성 → GitHub push
```
