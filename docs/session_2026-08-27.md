### 1. 웹사이트 미업데이트 문제 근본 원인 파악 및 영구 해결

**증상**: 매일 홈페이지에 오늘 경기가 표시되지 않는 일이 반복됨

**원인**:
- `scorecard_pipeline.py`는 `output/predictions_YYYY-MM-DD.js` 저장 후 종료
- 웹사이트(`mlb-scorecard-web`)는 `public/predictions.json`을 별도로 읽음
- 두 repo 간 자동 동기화 로직이 없어 매번 수동 복사 필요

**해결**:
1. `scorecard_pipeline.py` 저장 단계에 웹 폴더 자동 동기화 추가
2. `main.py`에 `cmd_deploy_web()` 함수 추가 → GitHub push 자동화
3. 이제 `python3 main.py` 실행 한 번으로 예측 + 웹 배포 완료
